# Agent Factory — portable workspace

Classify each request as OBSERVE/DISCUSS (read-only), RECORD (durable context),
EXECUTE (bounded delivery), or ADMIN (host/access/deployment).
Access capability is never blanket authority.

## Start progressively

For installation read docs/portable/INSTALL.md.
For a new or imported project read its docs/products/<slug>/AGENTS.md and
docs/portable/ONBOARDING.md. Never assume a project is ready because files exist.
Read docs/portable/DELIVERY.md before delivery.

The PO owns product definition and decisions. The Mayor alone orchestrates
executable work through Gas City and Beads. GitHub owns code/PR/check truth.
Use upstream commands; do not build a second task runner.
One writer per rig. Do not start or restart another City during installation.
Monitoring uses no models; a PO call requires an explicit user action.

Distinguish TARGET / CONFIGURED / OBSERVED / PROVEN. Record evidence and source
dates. Put durable decisions in Git and transient work in Beads.
Secrets, local profiles, runtime state and credentials never belong in Git.
For meaningful changes use a branch, scoped tests and a PR.
