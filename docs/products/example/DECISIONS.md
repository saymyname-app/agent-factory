# Example Product — decisions

## Accepted

### 2026-09-15 — Example core loop is the product

The pack proves one loop end to end before anything else. Every capability in
the configuration traces back to that loop or is deferred.

### 2026-09-15 — The pack is data, never code

A product declares itself with a configuration file, a release contract and a
documentation folder. No product string belongs in the cockpit core.

## Open

### Product

- **Example retention rule** — how long an example run should be kept before it
  is discarded is left deliberately open in this fixture.

### Enterprise

- **Example first buyer** — who would pay for the loop is intentionally not
  decided here.

### Project

- **Example view ownership** — which surface owns the loop's main view is left
  open so the cockpit has a project-domain decision to project.
