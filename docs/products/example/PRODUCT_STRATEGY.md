# Example Product — strategy

Reference product pack used to prove that the Agent Factory cockpit core stays
agnostic. Nothing here describes a real product; it exists so a second product
can be loaded, projected and tested without touching cockpit code.

## Product thesis

Example Product exists to demonstrate the shape a product pack must have: a
thesis, an ordered roadmap, explicit decisions, an inventory of views and a
design governance rule. A team adopting the Factory replaces this pack with
their own and changes no core file.

## Product roadmap

1. Prove the loop — a first user completes the core action end to end.
2. Prove the cohort — a small real group returns without hand-holding.
3. Prove the offer — one buyer accepts a priced, repeatable version.

Items below the roadmap are intentionally absent: this pack is a fixture.

## Measurement

A pack is healthy when the cockpit can project it without warning and every
configured reference resolves to a real section of a real document.

## Explicitly deferred or prohibited by default

This example never describes real users, real data or a real release. It must
not be used as a template for legal, privacy or security commitments.
